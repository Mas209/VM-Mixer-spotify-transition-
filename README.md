# VM-Mixer-spotify-transition-

## What is VM Mixer?
VM Mixer is an alternative for the spotify mix feature that makes you able to create your own transitions in an easy way between every song.

![description]([https://ibb.co/k2dg1ygZ](https://imageupload.app/i/fc3ddfae93aa79f12e91))

## How to use it?
The same way you use spotify mix with some additions, instead of looking for the songs you want you import them from an already made playlist link.

And it stores the songs in a file location of your choice so you don't have to redownload them every time.
